## About the Project

TechCart is a responsive mini e-commerce website built to demonstrate practical front-end web development skills using HTML, CSS, and JavaScript.

The project simulates an online technology store where users can browse products, search for products, filter products by category, and manage items in a shopping cart.

---

## Features

* Responsive e-commerce layout
* Product catalogue
* Product search functionality
* Category filtering
* Add-to-cart functionality
* Shopping cart
* Increase and decrease product quantities
* Remove products from the cart
* Automatic cart total calculation
* Cart item counter
* LocalStorage for saving cart data
* Responsive design for different screen sizes
* GitHub Pages deployment

---

## Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Interactivity and application logic
* **LocalStorage** — Persistent shopping-cart data
* **GitHub Pages** — Website deployment
